# 🧩 Kanoodle Web App - Puzzle Game

Una riproduzione web interattiva del celebre gioco di logica e rompicapo **Kanoodle** (o Polysphere). L'obiettivo del gioco è posizionare correttamente sul campo da gioco tutti i pezzi colorati formati da sfere collegate, completando la griglia.

---

## 🚀 Come Avviare l'Applicazione

L'applicazione è completamente web-based e **non richiede alcuna installazione**, web server o dipendenza esterna (Node.js, Python, ecc.).

### **Istruzioni:**
1. Assicurati di **lasciare la cartella del progetto così com'è**, senza spostare, rinominare o eliminare i file interni (CSS, JavaScript, immagini, ecc.).
2. Fai semplicemente un **doppio clic sul file `index.html`** (o aprilo con il tuo browser preferito: Google Edge, Chrome, Firefox, Safari).
3. Il gioco si aprirà e sarà subito pronto all'uso!

---

## 🎮 Controlli e Comandi da Tastiera

Giocare è semplice ed intuitivo grazie al supporto combinato di mouse e tastiera:

| Azione | Comando / Tasto | Descrizione |
| :--- | :--- | :--- |
| **Seleziona pezzo** | `Clic Sinistro` | Clicca su uno dei 12 pezzi disponibili nel pannello di destra. |
| **Posiziona pezzo** | `Clic Sinistro` | Clicca sul campo di gioco per posizionare il pezzo selezionato. |
| **Ruota pezzo** | <kbd>R</kbd> | Ruota il pezzo attualmente selezionato di 90 gradi. |
| **Capovolgi pezzo** | <kbd>F</kbd> | Capovolge / riflette (Flip) il pezzo selezionato specularmente. |
| **Rimuovi pezzo** | <kbd>Canc</kbd> / <kbd>Delete</kbd> | Rimuove il pezzo selezionato dal campo di gioco. |

---

## ✨ Caratteristiche Principali

* **Campo di Gioco Dinamico**: Griglia ad incastro per ospitare i vari blocchi sferici.
* **12 Pezzi Unici**: Ogni pezzo ha una forma e un colore distintivo (numerati da 1 a 12).
* **Contatore di Progresso**: Monitora in tempo reale quante caselle sono state riempite (es. `0 / 55`).
* **Pulsante Svuota Campo**: Consente di resettare la griglia con un solo clic per ricominciare una nuova partita.
* **Design Moderno e Responsive**: Interfaccia scura con rendering grafico 3D-like pulito ed elegante.

# 🧩 Kanoodle Web App - Puzzle Game

An interactive web reproduction of the famous logic puzzle game **Kanoodle** (or Polysphere). The goal of the game is to correctly place all the colored pieces made of connected spheres onto the board to complete the grid.

---

## 🚀 How to Run the Application

The application is entirely web-based and **does not require any installation**, web server, or external dependencies (Node.js, Python, etc.).

### **Instructions:**
1. Make sure to **leave the project folder as it is**, without moving, renaming, or deleting any internal files (CSS, JavaScript, images, etc.).
2. Simply **double-click the `index.html` file** (or open it with your preferred browser: Edge, Chrome, Firefox, Safari).
3. The game will open and be immediately ready to play!

---

## 🎮 Controls and Keyboard Shortcuts

Playing is easy and intuitive thanks to combined mouse and keyboard support:

| Action | Control / Key | Description |
| :--- | :--- | :--- |
| **Select piece** | `Left Click` | Click on one of the 12 available pieces in the right panel. |
| **Place piece** | `Left Click` | Click on the game board to place the selected piece. |
| **Rotate piece** | <kbd>R</kbd> | Rotate the currently selected piece by 90 degrees. |
| **Flip piece** | <kbd>F</kbd> | Flip / mirror the selected piece. |
| **Remove piece** | <kbd>Del</kbd> / <kbd>Delete</kbd> | Remove the selected piece from the game board. |

---

## ✨ Key Features

* **Dynamic Game Board**: Interlocking grid designed to fit the various spherical blocks.
* **12 Unique Pieces**: Each piece has a distinctive shape and color (numbered 1 to 12).
* **Progress Counter**: Tracks in real time how many cells are filled (e.g., `0 / 55`).
* **Clear Board Button**: Allows you to reset the grid with a single click to start a new game.
* **Modern & Responsive Design**: Dark interface with a clean and elegant 3D-like graphic rendering.
